# Code of Conduct

This project adheres to the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating, you agree to uphold this code. The full text is at the link
above; the project does not maintain a fork of it.

## Reporting

Reports go to `conduct@wardenbot.ai`. All reports are reviewed promptly and
handled confidentially.

## Enforcement

Project maintainers are responsible for clarifying acceptable behavior and
will take appropriate action in response to behavior they deem inappropriate.
